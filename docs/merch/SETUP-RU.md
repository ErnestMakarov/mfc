# Корзина мерча MFC

## Как запустить полный проект

Требуется Node.js 22.12+ (или 20.19+) и npm. В корне распакованного проекта выполните:

```bash
npm ci
npm run dev
```

Vite покажет адрес локального сайта, обычно `http://localhost:5173`.

## Как работает заказ

1. Откройте `/merch`, выберите товар.
2. На странице товара выберите размер и количество, затем нажмите «Добавить в корзину». Формы отправки email на странице товара больше нет.
3. В `/merch/cart` можно просмотреть все выбранные товары и размеры, изменить количество, удалить позицию или очистить корзину. Содержимое сохраняется в `localStorage` браузера.
4. Нажмите «Перейти к заявке». На `/merch/checkout` заполните имя, фамилию, email, при желании телефон и подтвердите согласие.
5. Отправляется одна общая заявка EmailJS со всеми товарами. Онлайн-оплаты нет: клуб подтверждает стоимость, наличие и получение отдельно.

Маршруты: `/merch`, `/merch/:slug`, `/merch/cart`, `/merch/checkout`.

## EmailJS — обязательно перед реальной отправкой

В архиве нет `.env.local`, потому что этот файл содержит локальные настройки и исключён из Git. Скопируйте `.env.example` в `.env.local` и укажите реальный Template ID:

```dotenv
VITE_EMAILJS_MERCH_SERVICE_ID=service_xfub9eq
VITE_EMAILJS_MERCH_PUBLIC_KEY=1rWXEQCaKSIe2JqzW
VITE_EMAILJS_MERCH_TEMPLATE_ID=template_ваш_id
```

Service ID и Public Key выше — уже используемые публичные значения проекта. Если в вашем аккаунте EmailJS другие данные, замените их. Не добавляйте Private Key в браузерный проект.

В EmailJS Dashboard откройте отдельный шаблон для заявок на мерч (не шаблон заявок на тренировки) и вставьте HTML из `docs/merch/emailjs-template.html`. Шаблон использует `{{order_items}}`, где находится полный список товаров, размеров и количеств. Укажите адрес клуба в **To Email**, а `{{reply_to}}` в поле **Reply To**. Сохраните шаблон и скопируйте его Template ID в `.env.local`.

После изменения `.env.local` перезапустите `npm run dev`. Для production задайте эти `VITE_` переменные в настройках хостинга и заново соберите сайт. Без настоящего Template ID приложение не отправляет запрос и показывает сообщение о настройке.

## Проверка перед публикацией

- Добавьте несколько разных товаров и один товар в двух размерах.
- Перезагрузите страницу и убедитесь, что корзина сохранилась.
- Проверьте изменение количества, удаление отдельной позиции и очистку корзины.
- На странице оформления проверьте обязательные поля и согласие.
- Отправьте тестовую заявку и убедитесь, что в письме присутствуют все товары, размеры, количество, контактные данные и номер заявки.
- Проверьте страницы на телефоне и компьютере, а также прямое открытие `/merch/cart` и `/merch/checkout` на хостинге.

Реальные письма в процессе сборки проекта не отправлялись. Наличие Template ID и правильность адреса получателя нужно проверить в вашем аккаунте EmailJS.
